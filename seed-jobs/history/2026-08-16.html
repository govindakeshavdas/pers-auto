1. Tracer 🔴 — Open-source AI SRE agent for automated incident root-cause analysis
tracer.cloud · New York (remote) · founded 2023 · VC-backed (amount undisclosed) · ~8–11 people · site · GitHub · job post
What they do
  • Open-source SRE agent that investigates incidents and finds root cause before engineers get paged.
  • Ingests an alert, assembles context from logs/metrics/traces, reasons across connected systems, posts a structured report to Slack or PagerDuty.
  • Uses eBPF-based data collectors at the OS level — no code changes needed.
  • Connects to 60+ tools across LLMs, observability, cloud infra, data platforms, and incident management.
The problem they solve
  • Evidence for a production incident is scattered: logs in Datadog, metrics in Grafana, config changes in Git. No single system sees all of it.
  • Engineers manually pull logs, correlate timestamps, and ping colleagues. Takes hours.
  • Example: alert fires at 3 AM for a K8s pod crash loop. Agent runs parallel hypotheses (bad deploy, resource limit, upstream timeout), tests each against live telemetry, delivers a root-cause report before the on-call engineer finishes reading Slack.
Money
  • Open-source core (Apache 2.0); commercial product presumably on top.
  • No public revenue figures. Still in public alpha.
  • Founded 2023 by Vincent Hus (CEO) and Laura Bogaert (COO). Started in bioinformatics observability, pivoted to general AI SRE.
Why now
  • SWE-bench gave coding agents training data and clear feedback. Production incident response still lacks an equivalent.
  • LLMs now good enough to reason across heterogeneous telemetry signals.
Bootstrap fit
  • Grader: Root-cause correctness is verifiable against the actual fix. Passes.
  • LLM deleted: eBPF collectors, 60+ integrations, eval harness remain. Passes.
  • Accumulates: 🔴 Incumbents already ship this as a feature. Datadog, PagerDuty, Resolve.ai all native.
  • Week one: 🔴 Needs live integration into customer's monitoring stack.
  • Buyer: SRE/platform-eng teams. Reachable, would pay.
Verdict: 🔴 — Fails gate 3 (durability) and gate 4 (cold start). Datadog Bits AI, PagerDuty SRE Agent, New Relic SRE Agent, AWS DevOps Agent, and incident.io AI SRE all ship native AI SRE agents. Resolve.ai reached $1B valuation faster than any competitor. This is a feature the observability platforms absorb, not a standalone product a solo founder can defend. Also requires live hooks into the customer's monitoring stack — cold start for a bootstrapper. Also: company founded 2023, outside the 2025–2026 window.
Crowding
  • Six agents dominate in 2026; choice usually follows existing stack. Plus 15+ more tools in comparison lists.
  • Every major cloud provider shipped a native AI SRE product in the last 12 months.
