1. Shiplight AI 🔴 — Agentic QA testing for AI coding agents
AI testing · San Francisco · Founded 2025 · Pre-seed (~undisclosed, Pear VC + Embedding VC) · ~2–10 people
shiplight.ai · Job posting
What they do
  • AI agents that generate, run, and maintain browser-based E2E tests.
  • MCP server plugs into Claude Code, Cursor, or Codex — no account needed.
  • YAML tests transpile to Playwright — real exit path if you leave.
  • Self-healing locators use natural-language intent, not DOM selectors.
The problem they solve
  • Dev velocity is no longer limited by humans writing code — it's limited by humans proving code works.
  • Example: coding agent ships a login flow; Shiplight opens a real browser, verifies the flow, and writes a regression test — all inside the same MCP session.
  • Maintenance ceiling: ~100–200 E2E tests per QA engineer before upkeep eats all writing time.
Money
  • SaaS — full test management platform with cloud execution.
  • Revenue/pricing not disclosed.
  • Very early stage: 2–10 employees, recently emerged from stealth.
Why now
  • Term emerged 2024–2025 alongside coding agents; as agents author code, testing must operate at the same autonomy.
Bootstrap fit
  • Grader: Browser pass/fail is objective; screenshots + DOM state are evidence.
  • LLM deleted: MCP server, YAML format, Playwright transpiler remain — technical system, not domain.
  • Accumulates: 🔴 Nothing unique. Playwright's own Test Agents already plan, generate, and heal Playwright code; BrowserUse does the same. Thin layer the platform absorbs.
  • Week one: Not reached.
  • Buyer: Not reached.
Verdict: 🔴 — fails gate 3. Playwright is shipping native agent test capabilities. YAML format and MCP wrapper are a thin layer with no accumulating asset.
Crowding
  • Playwright first-party Test Agents, Playwright MCP, and BrowserUse all compete directly.
  • Dozens of "AI QA" startups (QA Wolf, Testim, Mabl) plus open-source browser-agent frameworks.

neuromorphiclabs.ai · Job posting (Aug 2026)

  • No revenue disclosed.
  • Founder was CPO at CoreWeave through IPO; previously led AI infra at AWS.

5. Worktrace AI 🔴 — Workflow discovery + automation recommendations via screen observation
Enterprise automation · San Francisco · Founded 2025 · Seed ($9M, 8VC + Conviction) · ~14 people
worktrace.ai · Job posting
What they do
  • Desktop app runs in the background, observes work across tools to find AI automation opportunities — no integrations needed.
  • Surfaces recommendations tailored to company KPIs on how to reimagine processes with AI.
  • Generates automation blueprints for third-party platforms like n8n, Crew AI, and Asteroid.
The problem they solve
  • AI has moved faster than organizations' ability to understand their own work. The bottleneck is not models but mapping what people actually do.
  • Example: ops team spends 4 hours/day copying data between Salesforce and a spreadsheet. Worktrace spots the pattern and outputs an n8n automation blueprint.
Money
  • $9M seed co-led by 8VC and Conviction.
  • Co-founded by ex-OpenAI product leader Angela Jiang and a UIUC professor.
  • Revenue model: enterprise SaaS (likely per-seat or per-team).
Why now
  • Screen-level agents can now identify repetitive patterns and invisible workflows that traditional API integrations miss.
Bootstrap fit
  • Grader: 🔴 Workflow observation is mechanical, but the core output — "reimagine your processes" and "high-ROI automation opportunities" — is consulting judgment. Deciding what is worth automating and how to redesign workflows is subjective taste.
  • LLM deleted: Not reached.
  • Accumulates: Not reached.
  • Week one: Would also fail — needs desktop deployed on employee machines + their screen data. Useless without their workflow data (cold start).
  • Buyer: Not reached.
Verdict: 🔴 — fails gate 1 (+ gate 4). Core output is subjective recommendations about what to automate. Even if gate 1 were arguable, value only appears after capturing employee screen data — cold start.
Crowding
  • Process mining incumbents (Celonis, UiPath Process Mining, Microsoft Process Mining) do workflow discovery from system logs.
  • Screen-level approach is newer — Worktrace's differentiation — but also pursued by UiPath's task mining and emerging startups.
