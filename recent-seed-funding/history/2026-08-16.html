1. Devplan — 🔴 — AI intelligence layer for product & engineering coordination
devplan.ai · Seattle · $2.5M seed (June 2026)
What they do
  • Connects GitHub, Jira, Linear, Slack, Notion, and meeting notes into a knowledge graph.
  • Replaces status meetings and stale roadmaps with real-time, personalized views of risk and change.
  • Helps product and engineering teams coordinate as AI-assisted coding accelerates delivery.
The problem they solve
  • AI coding tools made building faster, but coordination tools have not kept pace — teams still waste hours gathering context.
  • Example: PM asks "what shipped last sprint?" and digs through Jira, Slack threads, and PR descriptions for 30 min.
  • Status updates, stale roadmaps, and alignment meetings compound as code execution speeds up.
Fit
  • Gate 1 — Subjectivity: Pass. Aggregates factual project status, not taste.
  • Gate 2 — Can I start: Pass. All tool APIs are public; build connectors in week one.
  • Gate 3 — Moat: 🔴 Fail. Delete the LLM and it's API reads plus a schema. Atlassian Intelligence, GitHub Copilot, and Linear AI already ship native summaries across their own data. A cross-tool layer is exactly what each platform absorbs next.
Verdict: 🔴 — tool, not a company. No durable accumulation; platform vendors own the data and are adding this.
Crowding
  • Atlassian Intelligence (Jira + Confluence AI), GitHub Copilot Workspace, LinearB, Jellyfish, Swarmia.
  • Tracxn lists competitors as Box, Pipefy, and Moveworks.
